# QA Upskilling - 45 Days

## Goal

Build strong skills in Java, Manual Testing, Selenium Automation, API Testing, CI/CD, and AI for QA.

## My 45-Day Goals

- Strengthen Java programming fundamentals
- Learn Selenium automation with Java
- Build a real automation framework
- Learn API testing and automation
- Learn Git and GitHub properly
- Understand CI/CD and Jenkins/GitHub Actions
- Learn how AI can be used in QA
- Build a portfolio project
- Become confident for QA Automation Engineer interviews
- Prepare for remote QA Automation opportunities

## Daily Practice

- 1 hour: Learn
- 1 hour: Practice
- Push my work to GitHub
- Avoid copy-pasting code
- Review and fix mistakes
